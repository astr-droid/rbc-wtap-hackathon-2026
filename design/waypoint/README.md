# Waypoint design files

- canvas/: Design-canvas sources (.dc.html + canvas.json) for the eight screens. These are design-canvas sources, not a Vite drop-in. Port to React by lifting the markup, CSS and the map camera math.
- deck/: Slides source for the 7-minute pitch (deck.json, deck.css, slides/*.html).
- Product name is Waypoint (the repo calls it Compass).
- Nothing was rendered or tested at runtime.
